# 田地 Dee · AI 产品与运营作品集

线上地址：https://tiandee0801-stack.github.io/website/

面向面试与职业合作的静态个人作品集，包含首页与三个可独立分享的案例。

## 本地预览

在仓库目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000/`。
也可直接打开 `index.html`；通过 HTTP 预览更接近 GitHub Pages 环境。

## 目录

- `index.html`：个人介绍、案例入口、方法、经历、内容与联系
- `case-ankle.html`：个人脚踝复训产品与 AI 系统设计
- `case-health-ai.html`：海外运动健康 AI 服务工作复盘
- `case-operations.html`：AI Native 运营提效工作复盘
- `assets/style.css`、`assets/site.js`：共享样式与交互

## 更新与发布

GitHub Pages 沿用本仓库现有发布源。所有本地资源均使用相对路径，支持 `/website/` 子路径部署。

更新首页和案例时，请同步核对实际产品状态。机制示意用于说明设计，不是在线 AI 服务；已公开、MVP 与后续规划分别说明。工作案例未包含内部代码、系统入口或用户数据。

页面不需要构建工具，不使用外部字体、分析脚本或后端服务。照片、简历与个人内容版权归田地 Dee 所有。

公开版本保留自媒体联系入口，不包含个人邮箱、手机号或简历 PDF。

## 动效与外观

桌面采用固定身份侧栏，内容区使用滚动入场、首屏分段出现、卡片悬停与轻量流程动效。支持日夜切换；键盘 `D` 为日间，`N` 为夜间。外观仅存储在当前浏览器，不上传数据。系统开启“减少动态效果”时自动停用动画。
